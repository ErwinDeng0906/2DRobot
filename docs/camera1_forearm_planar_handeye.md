# Camera1固定高度平面手眼与Task13

## 为什么新增这项标定

Stage3能看到托盘相对相机的位置，Stage4知道固定工作平面上的吸盘点相对相机的位置，但托盘旋转后还需要知道相机平面方向相对机械臂world的关系。一次性平面手眼标定得到 \({}^F R_C\)，使实时Stage3结果可以转换为本次Tray→World登记。

F的定义固定为J4轴中心、朝向 \(J1+J2\)。相机1不随J3/J4运动，因此J4和末端Rz不能作为相机朝向。

这项标定只支持固定高度平面XY，文件中必须保存：

```json
"z_supported": false,
"full_6dof_supported": false
```

## 现有Task8/Task12拟合

工具：

```text
tools/fit_planar_handeye.py
```

处理原则：

- 每个槽的重复帧先进行鲁棒聚合；
- 一个槽只算一个独立机器人姿态；
- Task8和Task12共享R_F_C，各自拟合独立W←T；
- P00/P05/P25/P45排除；P01/P10仅压力验证；
- 验证按完整槽位留出，不随机拆分同槽帧；
- 内参、Tray geometry、Stage4和源points.json全部hash锁定。

安装质量门：独立姿态≥12、world跨度≥100 mm、J1+J2跨度≥30°、所有训练/留出姿态的J3与Stage4观察高度偏差≤0.05 mm、留出XY RMS/P95/max分别≤0.50/0.80/1.20 mm、yaw RMS/max≤0.20/0.50°。经操作人员明确授权，跨run旋转外参差上限由0.30°放宽为≤1.00°；接近1.00°仍属于低余量结果，报告必须保留实测值。

2026-08-17对现有Task8 `260814171235` 与Task12 `260816224730`的只读回放结果：

- 独立训练姿态26个；world跨度145.775 mm；J1+J2跨度49.523°；固定J3最大偏差0.0072 mm；
- 留出XY RMS 0.376 mm、P95 0.507 mm、最大0.535 mm；
- 留出yaw RMS 0.178°、最大0.351°；
- 跨run旋转外参差1.191°，即使使用放宽后的1.00°门仍不通过。

因此现有数据不会被强行安装，必须运行Task13。

## Task13（不依赖Task12）

文件：`Tasks/task13_planar handeye.py`

Task13严格从`scara_presets.json`中的`P22 float`开始并最终返回同一个预设点。其余15个观察姿态由固定的槽位集合、刚体Tray geometry以及`P22 float`实时生成；Task13不读取Task12报告、Task12图片或Task12记录的机器人姿态。每姿态采集10张相机1照片，至少8张有效帧才形成一个独立姿态；槽间路线拆成≤0.60 mm端点步，固定J3和绝对Rz。

Task13完成后的平面手眼拟合使用Task8与本次Task13作为两个独立run。Task12只保留为此前可观测性诊断及历史候选拟合证据，不再是Task13的运行或安装依赖。

用户不需要重新测量托盘尺寸、相机偏移或36槽坐标。运行前只需：

1. 托盘夹紧，采集期间不移动；
2. 在UI预设点中执行`P22 float`，确认机械臂已经到达该点；
3. 确认全路线无障碍、急停可用、真空关闭且不带硅片。

Task13运行时会离线调用Stage3处理全部照片，按完整槽位验证。成功后原子安装：

```text
src/scara/calib/camera1_forearm_planar_handeye.json
```

失败时只保存`task13_planar_handeye.json/.md`，不会替换已安装文件。

安装文件包含`installation_check`字段。当前没有人为设定日历有效期，因此不会凭空假设“多少天后过期”；如以后填写`valid_until`或置`expired=true`，运行时会转入三姿态复核。相机1在同一应用会话内重新连接也会自动触发三姿态复核。
