# 所选硅片XY悬空对准

更新日期：2026-09-02
开发分支：`agent/camera2-guided-transfer`

## 1. 功能边界

本功能使用相机1将吸盘的XY位置移动到用户所选正常硅片槽位的正上方，并在XY到位后用J4对齐托盘方向：

1. J3始终保持相机1标定的安全观察高度。
2. 不执行下降、接触或拾取。
3. 不打开真空，不写入任何DO。
4. XY移动期间J4用于维持相机1标定绝对Rz；XY到位后只旋转J4，使工具绝对Rz等于本次`W←T`测得的托盘yaw，即工具X/Y轴与托盘X/Y轴平行。
5. 相机2、近距槽边缘识别和Task15/16不参与本功能。

## 2. 计算链

1. 相机1识别外围marker和槽内marker；2张正常`occupied`帧建立槽位锁。最多2张临时掉检可保留锁，明确的非正常槽位状态仍会立即打断。
2. 固定6x6几何给出所选槽位在托盘坐标系T中的中心。
3. 5张机械臂静止、时间同步的新帧建立本次`W←T`。
4. 槽中心通过`W←T`转换到机械臂World XY；启动XY会话时锁定该世界目标。后续相机帧只用于验证`W←T`没有越界漂移，不会逐帧推动目标坐标。
5. `WaferPickXYPositioningSession`使用2张合格帧的中位数生成XY候选：距离大于15 mm时最多9.99 mm，5到15 mm时最多5 mm，2到5 mm时最多2 mm，随后降至0.5/0.25 mm精调。
6. `ActionWorker`重新读取控制器，独立验证关节目标、正逆运动学、起终点、逐轴过渡路径、J3、Rz和工作域后才能下发。
7. 到位后使用同一两帧证据生成一次J4-only候选；`ActionWorker`确认J1/J2/J3及XY均不变后才执行，随后直接用控制器读回验证最终方向。

## 3. 硬性安全门

1. 只接受P00到P55的锁定槽位，且最新状态必须为正常单片`occupied`。
2. 每次XY运动请求使用2张全部通过的帧。短暂失败帧不会参与计算；两张合格帧间隔不得超过1.75秒。4秒内证据不足时本轮不运动并自动进入下一观察窗口；明确的质量门失败仍会停止。
3. 每步XY安全复核硬上限为10 mm；实际远距离候选最多9.99 mm，为控制器0.001 mm级回读量化保留余量。接近目标时自动降低步长。
4. 累计路径不超过200 mm，运动候选不超过100次。
5. 起点和终点必须在实时托盘中心正负65 mm的XY范围内。
6. J3对安全观察高度的偏差不超过0.20 mm；XY阶段当前绝对Rz偏差不超过0.30度、目标Rz偏差不超过0.15度。最终J4单独旋转不超过30度，最终绝对Rz相对托盘yaw不超过0.15度。
7. 控制器必须连接、使能、空闲、无报警、无急停，并且在T1模式且速度读回为`(0, 20%]`。
8. 提案产生后5秒失效；确认期间机械臂XY或关节变化超过0.10即作废。
9. `z_motion_authorized`、`vacuum_authorized`和`do_authorized`必须明确为`false`，否则ActionWorker在控制器调用前拒绝。
10. 单轮相机超时只跳过该轮；分析异常、明确质量门失败、用户关闭窗口或点击停止时，不再产生后续候选。

## 4. 现场使用

1. 确认吸盘不携带硅片，真空和所有相关DO为关闭状态。
2. 确认机械臂已在相机1标定的观察高度，托盘上方和逐轴扫掠路径无障碍，急停可随时使用。
3. 连接机械臂，选择T1模式，将速度设为20%或更低。
4. 连接相机源#1，打开「手眼交互 -> 转移视觉」。
5. 等待托盘位姿、`W←T`、机械臂时间同步和拾取稳定证据全部PASS。
6. 在「拾取槽」模式点击正常硅片，先使用「锁定拾取导航」观察坐标和偏差。
7. 点击「启动XY悬空移动」，核对目标名称、当前偏差和J3后ARM。
8. 运行期间不要移动托盘、相机或其他物体。画面偶发中断会显示“未运动，自动重试”；明确失败时先查看报告，不要绕过失败门。
9. 显示“已到达正上方，J4已使工具对齐托盘”后，机械臂仍处于观察高度。下降和吸取仍必须使用独立且尚未开放的流程。

## 5. 输出和检查

每次会话写入`Trajectory Photos/YYMMDDHHMMSS/`：

- `points.json`：ActionWorker的每轮request、proposal、两次运动学复核、真实控制器读回和最终状态。
- `wafer_pick_xy_positioning.json`：视觉会话的两帧窗口、安全门、误差、候选步长和终止证据。
- `pick_xy_*.png`：每轮使用的2张标注画面。

这里的“托盘是正的”是机械定义（工具坐标轴平行托盘坐标轴）。在缺少相机2到J4完整外参时，不能据此保证相机2画面在显示器上视觉水平；相机2画面方向需要单独外参标定。

当前代码已完成离线、运动学和协议回归测试，但未由自动测试连接实机执行。首次实验室使用应保持空吸盘、安全高度和人工监护，先选择距离当前吸盘最近的槽位验证方向与尺度。
