# 硅片裁图与物理槽界

硅片视觉中有两个不同的正方形，不能共用同一个尺寸。

## 1. Tray 刚体坐标

槽中心来自已经标定并经 hash 锁定的
`src/scara/calib/tray_board_geometry.json`。当前定义为：

- `P00 = (0, 0, -2) mm`；
- 行方向每格沿 `-X_T` 移动 25 mm；
- 列方向每格沿 `-Y_T` 移动 25 mm；
- 因此 `Prc = (-25r, -25c, -2) mm`。

本次修改不改写该刚体文件，避免使已有吸盘/手眼标定的 SHA256 失效。

## 2. 物理槽界

每个槽是边长 19.9 mm 的正方形。设槽中心为 `(Xc, Yc)`，则物理范围为：

```text
X_T in [Xc - 9.95, Xc + 9.95]
Y_T in [Yc - 9.95, Yc + 9.95]
```

例如：

- `P42` 中心 `(-100, -50, -2) mm`，物理槽界为
  `X=[-109.95,-90.05]`、`Y=[-59.95,-40.05] mm`；
- `P50` 中心 `(-125, 0, -2) mm`，物理槽界为
  `X=[-134.95,-115.05]`、`Y=[-9.95,9.95] mm`。

物理边长配置在 `silicon_detection_0818.json` 的
`tray_vision.physical_slot_side_length_mm=19.9`。

## 3. “裁图半宽 11.5 mm”

`tray_vision.slot_half_extent_mm=11.5` 表示：以槽中心为中心，向四周各取
11.5 mm，因此规范化视觉 patch 覆盖 23 x 23 mm。它比 19.9 mm 物理槽大，
目的是让槽外硅片仍保留在图中，便于恢复完整轮廓。

所以：

- 23 x 23 mm 只用于取图、分割和轮廓精修；
- 19.9 x 19.9 mm 才用于 `inside/outside` 几何判断和画槽框；
- 轮廓碰到 23 mm 裁图边缘不再自动等价于“槽外”。

边界判断使用拟合四边形在 Tray 坐标中的四个角，与槽中心 `±9.95 mm`
的物理正方形求交。考虑轮廓和投影误差，已完成槽内 marker 登记时使用
0.75 mm 不确定带；本帧 marker 不足、只能使用外围刚体投影时使用 1.5 mm
不确定带。不确定带内返回警告/不确定，不伪装成精确的 `OUT`。

## 4. 当前帧图像投影校正

外围 A-H marker 仍负责建立 Tray 刚体位姿。若当前帧能解码至少六个、且
空间分布合格的槽内 marker，系统使用其已知槽 ID 对 36 槽的图像投影做
有质量门的单应校正。该校正只改变图像中的槽框位置，不改变任何 Tray
坐标、吸盘标定或机器人运动标定；拟合不合格时自动回退到原 Stage-3 投影。
