# Task14：36槽自动曝光硅片检测扫描

## 用途

`Preset Trajectories/task14.py` 用于采集第一轮硅片检测参数修正数据。任务扫描全部
36槽，但预期有正常硅片的槽固定为：

`P01 P03 P14 P21 P30 P32 P33 P41 P44 P52 P55`

其余25槽预期为空。

## 运行方法

1. 将机械臂移动到已示教的 `P00 float` 固定观察高度。
2. 按上述清单放置正常硅片，确认其余槽为空；确认吸盘不携带硅片、真空关闭、全盘
   上方路径无障碍。
3. 在主UI导入 `Preset Trajectories/task14.py`。
4. 检查导入摘要应显示180张照片，然后运行并确认Task14专用安全提示。

ActionWorker 会在任何机械臂动作前打开相机1并显式请求自动曝光，任务结束前还会再次
请求自动模式；它不会写入固定曝光 `-1`。若驱动明确读回手动模式，任务拒绝运动；若驱动
接受 `0.75` 自动模式请求、但像本机UVC驱动一样对模式属性读回 `-1`，则把读回标记为
“仅供参考”而不是误判失败。此时不会再尝试用固定曝光回滚。所有任务相机默认执行同一
自动曝光策略；导入任务中的固定 `exposure` 设置会被拒绝。

任务沿Task12已经审计的相邻槽闭合蛇形路径扫描P00-P55。相邻槽之间只发送一次直接
关节目标，不再拆成大量0.6 mm微小中转步；运动速度沿用主UI当前选定速度，Task14不
写入速度。每槽到位后稳定0.6秒并连续拍5张，共180张；保持相同J3和绝对Rz，不下降Z、
不触发DO/真空、不进行视觉纠偏，结束后直接返回精确的 `P00 float`。

Task14检测固定从 `src/scara/calib/silicon_detection_0818.json` 加载完整参数。报告的
`locked_inputs` 记录配置绝对路径、配置名和SHA256，`tuning_scope` 中的当前值也来自
这份文件，因此不会再与手眼UI使用一套不同的内置参数。

## 输出位置

运行结束后，文件都位于本次对应的时间戳文件夹：

`Trajectory Photos/<运行时间>/`

- `task14_silicon_detection.json`：正式JSON报告。每一张照片都保存全部36槽的视觉结果，
  因此180张照片形成6480个原始槽观测；报告同时包含逐槽有效/排除统计、硅片Tray
  坐标/中心偏差、曝光写入证据和参数快照。
- `task14_silicon_detection_summary.md`：全视角中文报告。每个槽都统计全部180张照片中的
  有效观测，分别列出硅片槽的正常及其他各状态帧数、空槽的正确空槽及其他状态帧数，
  并列出各类被排除帧数。
- `silicon_detection_recommended.json`：根据本次已知正常/空槽标签生成的审阅用建议
  参数。它位于本次时间戳文件夹，不覆盖
  `src/scara/calib/silicon_detection_0818.json`，也不会自动应用。
- `1_001.jpg` 至 `1_180.jpg`：直接保存动态演示同款的TrayVision槽位与硅片标注图；
  文件名规则仍为 `1_XXX.jpg`。
- `raw_task14/`：未画标记的相机原始照片，文件名同为 `1_XXX.jpg`。报告复算始终读取这里，
  避免彩色轮廓和文字反过来干扰硅片识别。
- `annotated_task14/`：为兼容旧的报告查看方式而保留的标注图副本。
- `points.json`：原动作记录，并增加Task14目标槽、帧号和检测状态索引。
- `task14_silicon_detection_error.log`：仅在报告生成异常时出现。

报告状态：

- `normal_wafers_acceptable`：11个正常硅片槽的代表状态均为正常或警告。
- `tuning_required`：至少一个正常硅片槽仍被判为空、槽外或不可用。
- `invalid_exposure_evidence`：没有证据证明运动前和预热后均保持自动曝光，该批数据不
  应用于调参。
- `acquisition_stopped`：采集未完整结束。

## 全视角统计和排除规则

报告不再把“机械臂当前观察点”误当成该槽唯一的数据来源。每一张相机1照片都会分析
P00-P55全部36槽；对任意一个槽，候选数据源都是本次全部180张照片。

进入状态统计前按以下规则排除无效观测：

- 机械臂正对该槽拍摄的5张按吸盘遮挡高风险排除，即使算法偶然给出了状态也不采用；
- `out_of_view`、`occluded`、`unknown` 和 `unavailable` 排除；
- `empty_unread_marker` 表示二维码图案可见但未可靠解码，按“二维码无法识别”排除；
- Stage3/跟踪失败、槽结果缺失或处理异常排除。

当前正式配置把 `stacking_detection_enabled` 设为 `false`：叠片证据计算被临时跳过，
但相关函数和阈值完整保留，便于以后重新启用。硅片槽在剩余帧中只展示
`occupied`、`warning`、`outside_slot` 和误判为空槽的帧数。空槽分别统计可靠 `empty` 以及所有被判为
硅片或异常的帧数。参数建议只使用这些有效观测，不用正对槽吸盘遮挡帧或未知证据调参。

## 参数建议原则

Task14允许建议修改 `silicon_detection_0818.json` 中任何与硅片存在性或状态相关的参数，
但不会自动改变正式配置。报告对每项建议都写明旧值、新值和原因：

- 已知正常硅片因暗光或低饱和漏检时，只考虑调整HSV、暗色范围或色彩占比；
- 硅片大小判据允许建议调整：候选明确低于 `minimum_area_ratio` 时可以建议降低最小
  硅片面积；仅小幅高于 `maximum_area_ratio` 且不会接纳空槽候选时，可以建议提高最大
  硅片面积；已知正常硅片仅小幅触发 `oversize_footprint` 时，也可以建议调整
  `maximum_normal_side_ratio`。这些比例改变的是“多大候选算硅片”或硅片尺寸状态门槛，
  不是槽大小；
- 槽参数始终锁定：`tray_vision.slot_half_extent_mm`、
  `tray_vision.canonical_patch_size` 和 `wafer_quality.slot_boundary_margin_ratio` 不会写入
  Task14建议变更。槽外状态应检查托盘位姿、投影或硅片真实位置，不能通过修改槽大小消除；
- 现有 `260819154526` 实图复算的越界候选面积比为 `0.849–0.990`，多数远高于当前
  上限 `0.82`，原因是暗光掩码覆盖了大部分槽图。因此这批旧图不建议扩大最大硅片面积，
  但这不代表以后禁止根据有效自动曝光图片建议调整硅片面积门槛；
- 叠片检测临时关闭期间，Task14不生成叠片参数建议；
- 槽外状态不通过修改槽边界消除；应优先复核硅片分割轮廓是否粘连到槽图边缘；
- 若空槽已经出现占用误报，则不继续放宽颜色/面积门槛；
- `out_of_view`、`unavailable` 或位姿失败不通过硅片参数掩盖；
- 自动曝光证据无效时，建议JSON保持原参数。

正对当前机械臂观察点的5张按采集几何直接排除；其他视角不会仅凭猜测标记为吸盘遮挡。
其余漏检优先检查自动曝光图、`no_chromatic_candidate`、`marker_artifact_rejected` 和颜色
掩码。建议配置必须先查看标注图并做离线复算，确认后再通过手眼UI的“硅片判定参数”
按钮手动选择。
