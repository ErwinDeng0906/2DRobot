# 相机2近距引导实施记录

## 1. 分支基线

- 开发分支：`agent/camera2-guided-transfer`
- 起点：`origin/main` 提交 `410145b5b3e0f059e5bb1a6a6ba9ec635b6e551a`
- 安全边界：本阶段不接管ActionWorker的机器人运动，不修改Task15/16真机动作。

## 2. 本次已实现

1. 新增相机2到J4的完整刚体外参数据契约，坐标记法统一为 `T_A_B`，表示把B坐标中的点转换到A坐标。
2. 使用已标定的相机2内参检测ChArUco板，记录角点数、PnP内点率、重投影RMS和最大残差。
3. 用独立测量的标定板世界位姿 `T_W_B` 与同步机器人状态求解 `T_J4_C2`。
4. 对观测数、不同机器人姿态数、XY/J3/Rz覆盖、平移/旋转残差、内点率和标定板测量不确定度设置失效关闭质量门。
5. 校验 `points.json` 中 `mechanical_center` 是否与J1–J4正运动学、J3高度和Rz约定一致。
6. 只接受Task18运行目录，不会把Task14/17或其他轨迹数据混入外参求解。
7. 新增无运动Task18采集脚本、三点板位姿生成器、离线外参求解器、标注图和JSON报告输出。

## 3. 不会被假定的物理量

1. `T_W_B`：必须在实验室使用同一指针或测量工具触测ChArUco印刷棋盘的原点、+X和+Y参考点。
2. `T_J4_S`：如果 `mechanical_center` 不是吸盘中心，必须另行标定J4到吸盘中心的偏移。
3. J3安全高度、观察高度、拾取/放置接触高度：必须由实机和工装决定，不从单帧图像猜测。

## 4. 完成外参后的后续顺序

1. 标定J4轴心到真实吸盘中心 `T_J4_S`。
2. 按J3建立有限个固定近距观察profile，不做任意高度的单目绝对深度估计。
3. 采集相机2的正常对齐、XY偏移、Rz旋转、遮挡、反光和不同J3高度数据。
4. 实现只读的近距硅片/目标观测器，输出机器人XY/Rz修正量与不确定度。
5. 加入新鲜帧、机器人状态同步、多帧一致、修正上限、碰撞边界和闭环复测。
6. 最后由ActionWorker逐步审核运动；视觉UI本身不直接发送运动或DO指令。

## 5. 验证结果

- 新增外参求解、异常点排除、姿态覆盖、静止帧抖动聚类、板位姿、Task18无运动契约、机器人状态一致性和Task18目录筛选共12项测试通过。
- 连同非Qt的托盘定位、硅片几何、转移跟踪和参数契约，选定的69项回归测试全部通过。
- `tests/test_marker_grid_wafer_review.py` 在当前 `origin/main` 基线上有4项既有断言失败；该测试和实现文件与 `origin/main` 哈希完全相同，本分支没有调整这组硅片参数。
- macOS系统Python未安装 `PyQt6`，依赖Qt的UI测试需在项目规定的Windows Python 3.10环境内执行。
