4. 对观测数、不同机器人姿态数、XY/J3/Rz覆盖、平移/旋转残差、内点率和标定板测量不确定度设置失效关闭质量门。

6. 只接受Task18运行目录，不会把Task14/17或其他轨迹数据混入外参求解。
7. 新增无运动Task18采集脚本、三点板位姿生成器、离线外参求解器、标注图和JSON报告输出。

## 3. 不会被假定的物理量

1. `T_W_B`：必须在实验室使用同一指针或测量工具触测ChArUco印刷棋盘的原点、+X和+Y参考点。
2. `T_J4_S`：当前Task8和现场操作采用J4轴心与软吸盘中心同心的既有假设。固定Rz的
   相机1安全高度XY验证可继续使用该假设；若需要任意Rz或明显小于1 mm的精度，必须先做
   J4旋转跳动测试，并在发现固定偏心后标定J4到吸盘中心的变换。
3. J3安全高度、观察高度、拾取/放置接触高度：必须由实机和工装决定，不从单帧图像猜测。

## 4. 完成外参后的后续顺序

1. 先使用现有Task8吸盘目标完成固定Rz、无接触的相机1点击XY验证；J4旋转跳动测试作为
   任意Rz和亚毫米操作的前置质量门，而不是当前固定Rz测试的重复标定项。
2. 按J3建立有限个固定近距观察profile，不做任意高度的单目绝对深度估计。
3. 采集相机2的正常对齐、XY偏移、Rz旋转、遮挡、反光和不同J3高度数据。
4. 实现只读的近距硅片/目标观测器，输出机器人XY/Rz修正量与不确定度。
5. 加入新鲜帧、机器人状态同步、多帧一致、修正上限、碰撞边界和闭环复测。
6. 最后由ActionWorker逐步审核运动；视觉UI本身不直接发送运动或DO指令。

## 5. 验证结果

- 新增外参求解、异常点排除、姿态覆盖、静止帧抖动聚类、板位姿、Task18无运动契约、机器人状态一致性和Task18目录筛选共12项测试通过。
- 连同非Qt的托盘定位、硅片几何、转移跟踪和参数契约，选定的69项回归测试全部通过。
- `tests/test_marker_grid_wafer_review.py` 在当前 `origin/main` 基线上有4项既有断言失败；该测试和实现文件与 `origin/main` 哈希完全相同，本分支没有调整这组硅片参数。
- macOS系统Python未安装 `PyQt6`，依赖Qt的UI测试需在项目规定的Windows Python 3.10环境内执行。

## 6. 2026-08-28所选硅片XY悬空对准

1. 新增`wafer_pick_xy_positioning.py`，锁定一个P00到P55的正常单片槽位，使用实时`W←T`计算吸盘到槽中心的World XY偏差。
2. 每步只使用ActionWorker请求之后的5张连续处理帧；任一失败帧、重复帧、目标改变或误差不减小均终止。
3. 每步XY终点不超过2 mm，单轴不超过2 mm，且必须位于实时托盘中心附近的有限域内。
4. 启动、下发前、J4补偿后和到位后都要求T1模式、速度`(0, 20%]`、无报警、无急停且控制器空闲。
5. J3目标必须与当前安全观察高度相同；J4只允许用于维持标定绝对Rz。运行时协议明确要求`z_motion_authorized=false`、`vacuum_authorized=false`和`do_authorized=false`。
6. 到达判断需要最后独立5帧的距离中位数不超过0.50 mm、最大值不超过0.80 mm且帧间RMS不超过0.25 mm。
7. 证据保存在`Trajectory Photos/YYMMDDHHMMSS/points.json`、`wafer_pick_xy_positioning.json`和`pick_xy_*.png`。
